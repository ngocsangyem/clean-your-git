## Objective
Implement the shared core library with git operations, branch analysis, and branch management functionality.

### 2. packages/core/tsconfig.json
Extend from base config, output to dist/.

### 3. packages/core/src/types.ts
Define all TypeScript interfaces:
- BranchInfo (name, lastCommitDate, lastCommitHash, isMerged)
- AnalyzeResult (targetBranch, mergedBranches, unmergedBranches, totalBranches)
- DeleteResult (deleted: string[], failed: {branch, error}[])
- FilterOptions (pattern?, excludePattern?, olderThan?)

### 4. packages/core/src/git-operations.ts
Implement GitOperations class with simple-git:
- constructor(repoPath: string)
- isValidRepo(): Promise<boolean>
- getBranches(): Promise<string[]>
- getCurrentBranch(): Promise<string>
- isBranchMerged(branch, target): Promise<boolean>
- getBranchDetails(branch): Promise<BranchInfo>
- deleteBranch(branch): Promise<void>

### 5. packages/core/src/branch-analyzer.ts
Implement BranchAnalyzer class:
- constructor(gitOps: GitOperations)
- analyzeMergedBranches(targetBranch, filters?): Promise<AnalyzeResult>
- filterBranches(branches, filters): BranchInfo[]

### 6. packages/core/src/branch-manager.ts
Implement BranchManager class:
- constructor(gitOps: GitOperations)
- deleteBranches(branches, dryRun?): Promise<DeleteResult>

### 7. packages/core/src/validators.ts
Implement validation functions:
- validateRepoPath(path): {valid: boolean, error?: string}
- validateBranchName(name): {valid: boolean, error?: string}

### 8. packages/core/src/errors.ts
Define GitOperationError class extending Error with operation field.

### 9. packages/core/src/index.ts
Export all public APIs.

## Implementation Notes
- Use simple-git for all git commands
- Add proper error handling with GitOperationError
- Use zod for runtime validation where needed
- Add JSDoc comments to all public methods
- Follow kebab-case for file names
- Keep files under 200 lines
- Add type safety everywhere (no `any` types)

- Node.js 22
